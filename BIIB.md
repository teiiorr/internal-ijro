# BIIB — дизайн-система «Ichki Ijro»

Единый свод правил и компонентов. Цель — три принципа: **Красота · Лёгкость · Простота**
(_Krasota · Lyogkost · Prostota_). Этот документ — источник правды для UI; при сомнении
сверяйся с ним и с токенами в `src/styles/ui.css` / `src/app/globals.css`.

> Примечание: «·» выше — в заголовке markdown-документа, а не в UI. В интерфейсе средняя
> точка запрещена (см. правило 3). ESLint-гард (`no-restricted-syntax`) не даёт ей попасть в код.

## Жёсткие правила

1. **Основное действие — синее** (`--tint`, `#2563eb`). Золото/розовый не используются как
   акцент действия; розовый живёт только на тёмных glass-поверхностях поверх изображений.
2. **Заголовки — Manrope, слева.** `Heading` по умолчанию `align="start"`; центр — только явно.
   Цвет заголовка `--ink`, не золото.
3. **Никогда не используй среднюю точку «·» как разделитель.** Используй тире «—», запятую или
   просто расстояние. Проверяется ESLint-ом.
4. **Статус — угловая плашка `.tag-plate`**, не скруглённая «пилюля». Используй `Status`
   (`@/components/ui-biib/Status`) или `StatusTag` (`@/components/ui/status-tag`).
5. **Цвета статуса:** жёлтый (warning) / красный (danger) / зелёный (success) — и нейтральный,
   info (синий). Контраст — WCAG AA: amber использует тёмный текст, остальные — белый.
6. **Мобильные сетки — `grid-cols-1`** по умолчанию, расширяйся с `sm:`/`md:`/`lg:`.

## Компоненты (ui-biib)

- `Card` — `glass` / `solid` / `bare`. Внутри карточки нет вложенных «коробок в коробке».
- `Section` — заголовок + опц. `meta` / `action` / `seeAllHref` (призрачная кнопка «Barchasi» справа).
- `Heading` — уровни h1…h3, слева по умолчанию.
- `Button` — варианты `primary` (синий) и `ghost`; `iconOnly` требует `aria-label`.
- `Status` — угловая статус-плашка (тон: success/warning/danger/info/neutral).
- `FactList` / `Rows` / `Row` — списки без рамок вокруг ячеек (divide-y, не коробки).
- `PageHeader` — шапка страницы.

## Токены (CSS)

- Цвет: `--tint` (действие), `--ink` / `--ink-2` / `--ink-3` (текст по убыванию контраста),
  `--surface` / `--surface-2`, `--line` / `--line-strong`, `--ring` (фокус),
  `--success` / `--warning` / `--danger` / `--info`.
- Радиусы: `--radius-control`, `--radius-s`, `--radius-card`, `--radius-panel`, `--radius-media`.
  Не используй сырые Tailwind-радиусы (`rounded-lg` и т.п.) в фич-компонентах — только токены.
- Темы: светлая/тёмная задаются через `data-theme` + класс `.dark`; все цвета — через токены,
  чтобы обе темы работали автоматически.

## Доступность

- Фокус всегда виден: глобальное `:focus-visible` кольцо + принудительное кольцо для инпутов.
- Интерактив — на Radix (Dialog/Select/Tabs/Popover): фокус-ловушка, Escape, ARIA бесплатно.
- Иконочные кнопки — только из `@tabler/icons-react`, обязательно с `aria-label`.
- Контраст текста/статусов — не ниже WCAG AA.

## Чего не делать

- Не вводить вторую UI-систему: новые компоненты — в `ui-biib`.
- Не хардкодить hex-цвета в компонентах — только токены.
- Не использовать скруглённые «пилюли» для статуса и среднюю точку как разделитель.
